# financial-compliance-rag

> 金融合规知识库问答系统 —— 基于 RAG 的银行合规条线智能问答，回答可溯源、口径统一、知识可热更新。

## 项目背景

银行呼叫中心与合规条线的痛点：合规制度文件数量庞大、更新频繁，人工检索效率低、口径不统一。本系统用 RAG（检索增强生成）让大模型**只依据行内合规知识库作答**：答案带出处、知识库更新即生效、超出知识范围明确拒答（防幻觉）。

## 架构

```
corpus/（合规制度语料）
   │  离线入库：解析 → 切片 → 向量化 → 向量库
   ▼
向量库（当前内存版，计划 pgvector）
   │  在线问答：问题向量化 → Top-K 检索（含相关度闸门）
   ▼
检索结果 + 问题 → LLM（仅依据资料作答/拒答） → 带引用的回答
```

## 技术栈

Java 17 · Spring Boot 3.5 · LangChain4j 1.23 · BGE 中文嵌入模型 · DeepSeek（OpenAI 兼容协议）
